[問題 15]  以下の症例につき問に答えなさい。
41歳の女性。職場の同僚は彼女の外見が変化してきたことに気づいていた。目鼻立ちがごつごつと角張り、下顎が突き出て、歯の間に隙間ができてきていた。 帽子、靴、手袋のサイズが大きくなってきた。また指が太くなり指輪が入らなくなった。これらの不可解な症状の原因を知ろうと内科外来を受診した。
診察の結果、女性としては顔貌が角張りすぎ、かつ下顎がつき出ており、手足も異常に大きくなっていると医師からも指摘された。血圧は170/110だった。血液検査の結果を以下に示す。

検査値
空腹時血糖                            250 mg/dL (正常範囲：70-100 mg/dL)
空腹時成長ホルモン            90 ng/mL (正常範囲：2-6 ug/mL)

経口糖負荷試験のためにグルコースを内服した際、血漿中の成長ホルモン濃度は上昇したままだった。MRI画像検査ではトルコ鞍（下垂体のある頭蓋骨部位）に大きな腫瘤が確認された。医師は成長ホルモン分泌性下垂体腺腫による(a                 )と診断した。
外科手術により下垂体腺腫が摘除され、手術後成長ホルモンと血糖値は正常範囲に戻った。

 

( 1 )         ( a )にあてはまる言葉を答えなさい。

 

( 2 )         この病気の特徴的所見として頭蓋骨や手足の骨の過形成が生じる。なぜ生じるか説明しなさい。

 

( 3 )         本症例では長骨の成長は生じていない。なぜか。

 

( 4 )         空腹時血糖値が増加したのはなぜか。

[問題 17]  以下の症例について問に答えなさい。

54歳の男性。定期的に運動をして喫煙も飲酒もしない。体重を正常範囲に保っている。最近、全身の筋力低下と頑固な頭痛が続いている。市販の鎮痛薬は効かなかった。内科医を受診した。
身体診察では健康そうにみえた。しかし、血圧は180/100とかなり上昇していた。担当医は血液と尿検査を行い、以下の結果を得た。(Eq: eauivalent, 当量：モル数x 原子価 = 1当量)

検査値

動脈血              

pH                    7.50 (正常値は7.4)

動脈血CO2分圧         48 mmHg (正常値は 40 mmHg)

静脈血

Na+                   142 mEq/L (正常は 140 mEq/L)

K+                    2.0 mEq/L (正常は 4.5 mEq/L)

HCO3-                 35 mEq/L (正常は 23 mEq/L)

Cl-                   98 mEq/L (正常は105 mEq/L)

クレアチニン           1.1 mg/dL (正常は 1.2 mg/dL)

尿

Na+ 排泄量             200 mEq/24 hr

K+ 排泄量              1350 mEq/24 hr

クレアチニン排泄量     1,980 mg/24 hr

24時間カテコールアミン排泄量        正常範囲

        担当医は高血圧がレニン-アンギオテンシンII-アルドステロン系の異常によると考え、さらに下記の検査を行った。

                血漿レニン活性           低下

( 2 )         血漿のK+濃度が低かった理由を説明しなさい。

( 3 )         酸-塩基平衡はどのような状態になっているか、またどのような代償作用が働いているか。検査値を用いて説明しなさい。
