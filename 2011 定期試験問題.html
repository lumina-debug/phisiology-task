  14. [問題 14]    
    1. 以下の記述につき正しいものを全て挙げなさい。
      1. 尿中のK+濃度は血漿のそれよりも大きい。
      2. 血漿のCa2+濃度は尿中のそれよりも大きい。
      3. 尿中に含まれるタンパク質は通常測定にかからぬほど少ない。
      4. 腎血流量はPAHのクリアランスによって測定されうる。
    2. 以下の記述につき正しいものを全て挙げなさい。
      1. 腎には安静時の心拍出量の約1/5の血液が流れている。
      2. 運動中には心拍出量が増すと腎血液量が増える。
      3. 腎血液量は自動調節によって狭い範囲内に維持されている。
      4. 腎交感神経の活性が増加すると腎への血流増加をもたらす。
    3. 以下の記述につき正しいものを全て挙げなさい。
      1. 糸球体濾液の組成は、血漿の組成と同じである。
      2. 糸球体濾過量はイヌリンのクリアランスを用いて測定することができる。
      3. 糸球体濾過量は輸入細動脈の血圧に依存している。
      4. 腎尿細管による小さな分子の吸収は常に特異的な輸送タンパク質を介して起こる。
    4. 以下の記述につき正しいものを全て挙げなさい。
      1. 尿中へのグルコースの出現は近位尿細管のグルコース担体の飽和を反映している。
      2. 尿細管上皮によるグルコースとアミノ酸の輸送は、Na+輸送と共役している。
      3. もしある物質の腎クリアランスがイヌリンのクリアランスを上回る時には、その物質は尿細管で分泌されているはずである。
      4. 健康な人では近位尿細管は濾過グルコースの全てを再吸収している。
    5. 以下の記述につき正しいものを全て挙げなさい。
      1. 濾過された重炭酸は陰イオンとして吸収される。
      2. 全ての濾過重炭酸は通常近位尿細管の前半部で再吸収される。
      3. 全てのネフロンは髄質の奥深くまで入ったHenle係蹄を持っている。
      4. Henle係蹄の細い下降脚では水を透過する。
    6. 以下の記述につき正しいものを全て挙げなさい。
      1. Henle係蹄のヘアピン局部の液の浸透圧は1200 mOsm/kgを越えることもある。
      2. Henle係蹄の太い上行脚ではNa+を近位尿細管と同じ方法で輸送する。
      3. Henle係蹄の細い上行脚は水に不透過性である。
      4. Na+の取り込みは近位尿細管によって調節されている。
    7. 以下の記述につき正しいものを全て挙げなさい。
      1. 緻密班の細胞は、血漿のNa+濃度が低いときにレニンを分泌する。
      2. アンギオテンシンIIは肺血管の内皮に存在する酵素の作用によってレニンから作られる。
      3. アンギオテンシンIIは副腎髄質に作用する。
      4. 副腎はアンギオテンシンIIによる刺激に反応してアルドステロンを分泌する。
    8. 以下の記述につき正しいものを全て挙げなさい。
      1. 血漿K+は近位尿細管のナトリウムポンプ活動によって調節される。
      2. 遠位尿細管のCa2+吸収は副甲状腺ホルモンによって減少させられる。
      3. 近位尿細管のリン酸吸収は副甲状腺ホルモンによって調節されている。
      4. 遠位尿細管の介在細胞はHCO3-を再吸収するために管腔内液にH+を分泌する。
    9. 以下の記述につき正しいものを全て挙げなさい。
      1. 腎髄質は皮質との境界から腎乳頭にかけて増加していくような浸透圧勾配を持っている。
      2. 腎髄質の浸透圧勾配は、Henle係蹄の太い上行脚から周囲の間質液へのNa+とCl-の輸送から生じる。
      3. ADHは血液の浸透圧の減少に反応して下垂体前葉から分泌される。
      4. ADHは集合管に対して水の透過性を増すように働く。
