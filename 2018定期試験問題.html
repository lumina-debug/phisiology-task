2018年度 生理学A 定期試験問題

[問題 1]     以下の選択肢のうち正しいものを全て挙げなさい。
( 1 )   
(a)    酸素や二酸化炭素などのガスは脂質二重層を通しての受動的拡散によって細胞膜を透過する。
(b)    酸素や二酸化炭素などのガスは特殊な輸送体タンパク質によって細胞膜を透過する。
(c)    イオンはチャネルタンパク質を通しての拡散によって細胞膜を透過する。
(d)    物質は能動輸送によって電気化学的勾配に逆らって蓄積する。
(e)    物質はイオンチャネルによって電気化学的勾配に逆らって蓄積する。

( 2 )   
(a)    物質は共輸送によって電気化学的勾配に逆らって蓄積する。
(b)    Na+は主たる細胞内の陽イオンである。
(c)    ナトリウムポンプは細胞内Na+と細胞外K+を交換する。
(d)    ナトリウムポンプはATPを必要とする。
(e)    ナトリウムポンプはイオンチャネルである。

( 3 )   
(a)    分泌は細胞内Ca2+の増加が引き金となる。
(b)    細胞はエンドサイト—シスを細胞外スペースからの大きな分子の取り込みに利用している。
(c)    細胞はエンドサイト—シスをエキソサイトーシス後の細胞膜の構成成分の回収に利用している。
(d)    分泌は常に膜性の小胞が関与している。
(e)    Na+-H+交換は能動輸送を担う。

[問題 2]     下垂体後葉ホルモンを列挙し、それぞれを合成する細胞の存在する部位を答えなさい。

[問題 3]     細胞間シグナル分子の受容機構を分類し、それぞれを説明しなさい。。

[問題 4]     典型的な神経細胞の活動電位について、発生から終息までをNaチャネルとKチャネルの活性化、不活性化を踏まえて説明しなさい。

[問題 5]     糖質コルチコイドについて、
( 1 )    別名をひとつあげなさい。
( 2 )    構造上属する化合物グループを答えなさい。
( 3 )    作用を記述しなさい。次のキーワードを全て使うこと。
        キーワード：インスリン、グルコースの取り込み、グリコーゲン、糖新生、ストレス、アレルギー
( 4 )    合成される臓器とその中の部位の名前を答えなさい。

[問題 6]     甲状腺について、
( 1 )    甲状腺ホルモンについて，血液中の濃度を正常に維持するための機構について述べなさい。
( 2 )    飢餓状態になった際の甲状腺ホルモンの代謝について述べなさい。

[問題 7]     グルコースについて、
( 1 )    なぜ血糖値はある値以上に保たれなければならないか、説明しなさい。
( 2 )    血糖の供給メカニズムを５つ以上列挙し、関与する臓器とともに簡潔に説明しなさい。
( 3 )    血糖値が高い状態が長期間続くと何故健康を害するか。説明しなさい。
( 4 )    Ⅰ型糖尿病の患者は痩せている。何故か。

[問題 8]     ある患者に10g14Cラベルイヌリンと、3H2O 10 mLを含む静脈注射が行われた。90分後に、イヌリンの血漿濃度は0.3mg/mLであり、3H2Oは血漿1 mLにつき0.18 μLと等価であった。同じ期間内に、約5.2gのイヌリンと2.26mLの3H2Oが尿中に排泄された。次の項目を計算しなさい。
(1) 全水分量   
(2) 細胞外液量   
(3) 細胞内液量   
(4) 患者が正常成人男性と仮定したときのおよその体重   

[問題 9]     (1) 黄体は何から作られるか、答えなさい。
(2) 黄体の機能を答えなさい。
(3) 黄体の寿命を答えなさい。
(4) 黄体と胎盤の関係を答えなさい。

[問題 10]     血中へのカルシウムの出入りに関わる臓器を３つ挙げ、それぞれの臓器ごとにカルシウム代謝に関わるホルモンの働きを述べなさい。

[問題 11]     腎髄質で浸透圧勾配が維持されているメカニズムを説明しなさい。直血管についても言及すること。


[問題 12]     酸塩基障害について次の問に答えなさい。
(1) 図は血漿の pH-[HCO3-]ダイアグラムである。A〜Dにあてはまる病態（例：呼吸正アシドーシス）をそれぞれ書き、さらに、それぞれの病態の原因をひとつづつ挙げなさい。
2) 答案用紙にpH-[HCO3-]ダイアグラムを描き、呼吸性アシドーシスが腎により代償される前後の状態を書き入れなさい。更に、代謝性アルカローシスが 呼吸により代償される前後の状態も書き入れなさい。

[問題 13]     (1) アドレナリンの産生臓器とその中の部位、産生細胞の名称を書きなさい。
(2) アドレナリンの心臓・血管系に対する作用を説明せよ。
