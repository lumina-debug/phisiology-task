( 1 )    興奮性細胞では静止膜電位は大体どのくらいにあるか、値を答えなさい。

( 3 )    膜電位を一定に保っているメカニズムを説明しなさい。

[問題 4]     鉱質コルチコイドについて、

( 2 )    構造上属する化合物グループを答えなさい。
( 3 )    作用を記述しなさい。次のキーワードを全て使うこと。

( 4 )    合成される臓器とその中の部位の名前を答えなさい。

[問題 5]     グルコースについて、
( 1 )    なぜ血糖値はある値以上に保たれなければならないか、説明しなさい。

( 3 )    血糖値が高い状態が長期間続くと何故健康を害するか。説明しなさい。
( 4 )    Ⅰ型糖尿病の患者は痩せている。何故か。


[問題 6]     循環ショックについて以下の問に答えなさい。
( 1 )  循環ショックはどのような状態のことか。簡潔に答えなさい。
( 2 )  重篤な循環ショックにより死に至る過程について説明しなさい。   
( 3 )  神経原性ショックについて説明しなさい。   
( 4 )  敗血性ショックについて説明しなさい
